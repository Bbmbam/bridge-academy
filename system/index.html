1. Fundamental Rules of the System

Rule 1: Transfer First

เมื่อมีโอกาสใช้ Transfer ให้ใช้ Transfer ก่อน

เหตุผล: หา Major Fit ได้เร็ว / เก็บพื้นที่ประมูล / ซ่อนมือคนเปิด

Rule 2: Shape Before Strength

ก่อนถามแต้มให้หารูปไพ่ก่อน

ลำดับข้อมูล: Fit → Shape → Shortness → Control → Strength

ดังนั้น Game Force Relay ไม่ใช่ถามแต้ม แต่ถาม Shape

Rule 3: Strong Hands Speak

มือขั้นต่ำประมูลธรรมชาติ มือที่มี 16+ HCP จะมี Core Engine ในการแสดงพลัง

Rule 4: Ask Before Guessing

ห้ามเดา ถ้ายังมีพื้นที่ประมูล ให้ถามก่อน จึงเกิด:

  • Shape Relay
  • Transfer Checkback
  • Shape Stayman

Rule 5: Find Fit Before Game

เกมจะตัดสินหลังรู้ Fit แล้ว ไม่ใช่หลังนับแต้ม

ตัวอย่าง: 15 + 10 = 25 ไม่จำเป็นต้องได้เกมเสมอ และ 14 + 9 = 23 บางครั้งก็ได้เกม ถ้า Shape ดี

GAME TRY STRUCTURE

แนวคิด: เมื่อเราเจอทรัมพ์ Major ที่ระดับ 2 บางครั้งรวมกันยังไม่แน่ใจว่าได้ 25+ หรือไม่ ก็ต้องถาม min-max แต่การเอา Honor มาถูกตัวหรือมีชุดสั้น อาจไปเกมด้วยแต้มรวมน้อยกว่า 25 ได้:

  • 2M+1: asking min max + Honor
  • 2NT: สำหรับทรัมพ์ ♥ จะเป็น short suit ♠
  • 3m: short suit m Game Try

B. Response Negative 1♠

นิยาม: แต้ม 6-10 ไม่มี M4 และ ไม่มี minor 6+

C. Response 1NT Game Force Relay

นิยาม: ไพ่แต้มเกมต้องการรู้ Shape คนเปิด (1♣ – 1NT)

D. Response Level 2

2♣ = GI+ ♦5+ or NF ♦6 และ 2♦ = GI+ ♣5+
